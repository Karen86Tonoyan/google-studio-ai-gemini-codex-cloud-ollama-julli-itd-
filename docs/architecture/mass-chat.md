# Mass Chat

## Purpose

Mass Chat allows one prompt to be sent to multiple AI models simultaneously.

## Goals

- compare responses,
- identify disagreement,
- evaluate reasoning styles,
- support operator review.

## Example Flow

```text
Prompt
  -> Model A
  -> Model B
  -> Model C
  -> Model D

Responses
  -> comparison view
  -> validation layer
  -> operator review
```

## Future Features

- response ranking
- disagreement detection
- consensus scoring
- export reports
- audit integration
